# Belarus News Parser

Парсер белорусских новостей на Python.

## Используемые библиотеки

- requests
- BeautifulSoup
- lxml

## Что делает программа

Программа получает новости с сайта БЕЛТА,
обрабатывает HTML-код и выводит белорусские новости
с их названиями и ссылками.
